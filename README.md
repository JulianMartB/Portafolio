# Portafolio de Julián Martínez

Sitio estático para GitHub Pages.

## Publicarlo
1. Crea un repositorio llamado `TU-USUARIO.github.io` en GitHub.
2. Sube `index.html`, la carpeta `img/` y tu `cv.pdf` a la raíz del repositorio.
3. En Settings → Pages, elige la rama `main` y la carpeta `/ (root)`.
4. En uno o dos minutos queda en `https://TU-USUARIO.github.io`.

## Pendientes
- Tu foto ya está en `img/yo.jpg`. Para cambiarla, reemplaza ese archivo.
- Tu hoja de vida: súbela como `cv.pdf` en la raíz.
- Para abrir un proyecto directo, usa `#parlante`, `#organizador` o `#lancha` al final del link.
